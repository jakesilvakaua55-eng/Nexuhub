# LEIA PRIMEIRO — NexHub v35

Esta versão foi feita em cima do ZIP com dados da v34.

## O que testar primeiro

1. Entrar no app.
2. Abrir **Explorar**.
3. Abrir **Missões** e resgatar recompensa diária.
4. Abrir **Loja** e desbloquear um item grátis.
5. Testar status de atividade.
6. No painel do criador, testar selo de servidor e anúncio global.

## Testes automáticos

Foram executados:

- `npm run check`
- `npm test`

Resultado esperado: 28/28 testes passando.

## Atenção

Este ZIP contém os dados vindos do arquivo que foi usado como base. Não compartilhe publicamente se tiver contas, banco ou mídias reais.
